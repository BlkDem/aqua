# Живой аквариум

Интерактивный 3D-аквариум на Three.js: маленький подводный мир, который живёт сам по себе.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

Первая загрузка занимает несколько секунд: сцена строится процедурно (карта высот для креветок и улиток, мох, растения).

## Живой мир

Аквариум живёт по настоящему времени и сохраняется в браузере (`localStorage`), поэтому жизнь продолжается, пока вкладка закрыта:

- рыбы растут: малёк → подросток → взрослая → старожил; скорость роста зависит от вида;
- взрослые рыбы образуют пары, выбирают укромное место — и появляются мальки; они держатся у «детского сада» в растениях, заботливые виды их охраняют, подросшие вливаются в стаи;
- мальки наследуют от родителей оттенок, размер, вариант окраса и характер; изредка выпадает редкий окрас;
- растения подрастают и пускают побеги — появляются новые кусты;
- автокормушка кормит по расписанию (настройки: 2–4 раза в день, хлопья / гранулы / мотыль); голода, болезней и наказаний за отсутствие нет;
- важные события попадают в «Историю» (панель «Обитатели»), а при возвращении показывается «Пока вас не было…».

Для проверки: `?timescale=600` ускоряет время (секунда — 10 минут), `?away=48` изображает возвращение через 48 часов. В этих режимах используется отдельное сохранение, настоящее не трогается.

## Управление

| Действие | Как |
|---|---|
| Вращение / зум | мышь (ЛКМ, колесо), ПКМ — панорама |
| Выбрать рыбку | клик по ней (карточка, слежение камерой, переименование ✎) |
| Постучать по стеклу | клик по стеклу |
| Кормить | кнопка или `F` |
| Наблюдать / Cinematic | кнопки или `O` / `C`, выход — `Esc` |
| Скрыть интерфейс | `H` |
| Во весь экран | кнопка «Экран» (или `F11`): через 3 секунды без движения мыши курсор и панель кнопок прячутся, остаётся только аквариум и истории; любое движение возвращает их |

## Структура

```
src/
  main.js              рендерер, свет, ввод, главный цикл
  fx/shaderPatch.js    общие шейдерные доработки: каустики, колыхание растений, работа хвоста
  fx/particles.js      пузырьки (слияние/деление), взвесь, лучи света, корм
  fx/post.js           bloom, depth of field, грейдинг, letterbox
  fx/director.js       камера: пресеты, слежение, cinematic и режим наблюдения
  fx/audio.js          синтезированный звук: вода, фильтр, пузырьки, эмбиент
  fx/gpu.js            какая видеокарта рисует, поиск более мощной (WebGPU), инструкции по переключению
  world/tank.js        аквариум, стекло, вода, песок, фильтр, LED
  world/decor.js       расстановка декора: замок, коряга, корабль, сундук, пещера, руины, водолаз…
  world/decorAssets.js загрузка моделей декора и растений, роли частей (Glow/Sway/Glass)
  world/plants.js      расстановка растений, мох, травяной ковёр, кораллы, актиния
  world/daycycle.js    утро / день / вечер / ночь
  life/species.js      12 видов: форма, окраска, плавники, манера плавания, характер
  life/fishModel.js    процедурная модель рыбы
  life/fish.js         ИИ рыбы: состояния, стаи, территория, игры, память, мальки, пары
  life/world.js        сохранение мира, время, имена, история
  life/lifecycle.js    рост, стадии, пары, нерест, наследование, «пока вас не было»
  life/critters.js     креветки, улитки, крабик: поведение, походка, анимация суставов
  life/ecosystem.js    мир: истории, случайные и редкие события, кормление, секреты
  ui/ui.js             минимальный интерфейс
  pwa.js               установка как приложение, офлайн-режим, предложение обновиться
public/icons/          иконка (icon.svg) и её PNG-версии для манифеста, iOS и вкладки
tools/blender/
  make_fish.py         модели рыб           → public/models/fish
  make_decor.py        декор и кораллы      → public/models/decor (процедурные материалы запекаются в текстуры)
  make_plants.py       растения и мох       → public/models/plants
  make_critters.py     краб и улитки        → public/models/critters (части-суставы, общий запечённый атлас)
tools/import_fish.py   готовая модель рыбы (один меш с текстурой, например из Tripo) → public/models/fish
tools/import_crab.py   готовая модель краба → public/models/critters/crab.glb, разрезанная на суставы (ноги, клешни, глаза)
tools/import_critter.py готовые улитки и креветка, разрезанные на части (раковина, щупальца; сегменты брюшка, ноги, усы)
tools/fin_map.py       размечает плавники готовой модели (тип и расстояние от основания), чтобы шейдер двигал каждый плавник по-своему
```

Модели пересобираются в Blender без интерфейса, например:

```bash
blender -b -P tools/blender/make_decor.py -- public/models/decor castle ship
blender -b -P tools/blender/make_plants.py -- public/models/plants
blender -b -P tools/blender/make_critters.py -- public/models/critters crab snail-mystery
```

Готовые модели рыб (все, кроме лунной рыбы) подключаются без Blender: скрипт ставит модель спиной вверх (`--up=-z` для модели, лежащей брюхом вверх) и носом вперёд, подгоняет размер так, чтобы хвост начинался там, где его изгибает шейдер (`--peduncle` — доля длины от носа), упрощает меш и уменьшает текстуры. Глаза и плавники остаются нарисованными в текстуре модели. `--variants` делает по модели на каждый окрас, поворачивая оттенок текстуры от `--ref`; `--straighten` выпрямляет хвост, вылепленный изогнутым вбок.

```bash
python3 tools/import_fish.py "orange goldfish 3d model.glb" goldfish --nose +x --peduncle 0.564
python3 tools/import_fish.py ca5ed81c3251a08f15cc3ac957224fbe.glb betta --up=-z --peduncle 0.5706
python3 tools/import_fish.py 5e397364550eaa3053cdbec0e5c196e4.glb cichlid --up=-z --peduncle 0.7494 --ref "#ff5a1a" --variants "#ff5a1a" "#ffd21f"
python3 tools/import_fish.py 529fec33468e891fd614debb6bc0e6cf.glb angelfish --up=-z --peduncle 0.635
python3 tools/import_fish.py 529f45f9adc6ca50bee3f4ad32806952.glb barb --up=-z --peduncle 0.773
python3 tools/import_fish.py "fish 3d model.glb" cory --peduncle 0.7705
python3 tools/import_fish.py 3e6d0112b3480e9978c55a903008a82b.glb rainbow --up=-z --peduncle 0.8615
python3 tools/import_fish.py d35dee4bf297ea65c44eef958c67f3a7.glb discus --up=-z --peduncle 0.791 --ref "#ff6a1f" --variants "#ff6a1f" "#2ad4c8"
python3 tools/import_fish.py "clownfish 3d model.glb" clown --peduncle 0.7551
python3 tools/import_fish.py "colorful fish 3d model (1).glb" neon --nose=-x --peduncle 0.7229
python3 tools/import_fish.py "colorful fish 3d model.glb" guppy --peduncle 0.6131 --straighten --ref "#ff6a3d" --variants "#ff6a3d" "#ffb21f" "#3f8cff" "#ff3fa4" "#8a5bff" "#28d6a8" "#ff2f2f"
```

После импорта рыбы её плавники размечаются: `python3 tools/fin_map.py public/models/fish/<вид>.glb`. Плавник — тонкая пластина, поэтому инструмент ищет места, где за поверхностью близко лежит обратная сторона. Тип плавника он определяет по тому, где тот крепится к телу: хвостовой, спинной, анальный, брюшные или грудные. Без разметки сплошные плавники просто едут вместе с телом.

Краб так же: `tools/import_crab.py` отрезает от модели всё, что выходит за край панциря, и раскладывает это на 8 ног, 2 клешни и 2 глаза. Ногу узнаёт по касанию дна, слипшиеся ноги разводит по кончикам. Каждую конечность режет на сегменты по расстоянию вдоль неё, в клешне отдельно выделяет подвижный палец. Получается тот же набор узлов-суставов, что у краба из Blender, и этот же файл подходит Unity-версии.

```bash
python3 tools/import_crab.py "crab 3d model.glb"
python3 tools/import_critter.py snail-mystery 47f4c938fbe39cd68c779bede3581c77.glb
python3 tools/import_critter.py snail-ramshorn "snail 3d model.glb"
python3 tools/import_critter.py shrimp 449d2b8e561a3b6fc2591e9c8cd8443d.glb --out <unity>/Assets/Aquarium/Models/Critters/shrimp.glb --skins <unity>/Assets/Aquarium/Art/Textures/Critters/shrimp/skins
```

Запекание декора идёт в Cycles; если в системе есть GPU (OptiX/CUDA/HIP), он используется автоматически.

Имена рыб и найденные секреты сохраняются в `localStorage`, поэтому характер и имя конкретной рыбки сохраняются между запусками.

## Видеокарта

На ноутбуках с двумя видеокартами браузер часто рисует на встроенной, хотя аквариум просит мощную (`powerPreference: 'high-performance'`): сайт не может выбрать видеокарту сам, особенно в Chrome на Windows. Поэтому аквариум:

- узнаёт, на какой карте он запущен (`WEBGL_debug_renderer_info`), и через WebGPU проверяет, есть ли в системе ещё одна, более мощная;
- на встроенной графике при первом запуске сам ставит качество «Низкое»; если и на половинном разрешении меньше 24 FPS — снижает качество дальше;
- один раз для каждой видеокарты показывает плашку «Аквариум запущен на встроенной видеокарте» с инструкцией под систему и браузер (Параметры Windows → Графика, `chrome://flags/#force-high-performance-gpu`, панель NVIDIA, `DRI_PRIME`/`prime-run` в Linux);
- в Настройках → Изображение показывает текущую видеокарту и даёт выбрать предпочтение (мощная / экономная), оно применяется после перезапуска.

## Приложение (PWA)

Аквариум можно установить как приложение: в Chrome/Edge/Android — кнопкой «Установить как приложение» в Настройках → Аквариум (или значком в адресной строке), на iPhone/iPad — «Поделиться» → «На экран „Домой“». Установленный аквариум открывается в своём окне на весь экран.

Сервис-воркер собирает `vite-plugin-pwa` (Workbox, настройки в `vite.config.js`):

- сам код, стили, страница и иконки кэшируются при установке (precache, ~1 МБ) с ревизиями — после выхода новой версии старые файлы удаляются;
- модели (30+ МБ) не скачиваются отдельно: после первого запуска страница передаёт сервис-воркеру список уже загруженных моделей, и он берёт их из кэша браузера. Дальше они отдаются из кэша сразу и тихо обновляются в фоне (StaleWhileRevalidate);
- шрифты Google тоже кэшируются, так что после первого визита аквариум полностью работает без сети.

Новая версия не подменяет открытый аквариум внезапно: сверху появляется «Есть новая версия аквариума — Обновить». Открытая страница проверяет обновления раз в час. В режиме `npm run dev` сервис-воркер не регистрируется.

Иконки рисуются из `public/icons/icon.svg`; PNG-версии (192, 512, maskable 512, apple-touch 180, favicon 32) получены из неё рендером в Chromium.

## Деплой

Каждый пуш в `main` собирает сайт и выкладывает его на https://aqua.umolab.ru (GitHub Actions, `.github/workflows/deploy.yml`): `npm ci && npm run build`, затем `rsync` содержимого `dist/` в `/var/www/fastuser/data/www/aqua.umolab.ru` на `fp.cloud28.umolab.ru`. Запустить вручную можно на вкладке Actions → Deploy → Run workflow.

Для доступа нужен секрет репозитория `DEPLOY_SSH_KEY` — приватный ключ деплоя. Его открытая часть лежит в `~user1/.ssh/authorized_keys` на сервере с ограничением `command="/usr/bin/rrsync …/aqua.umolab.ru",restrict`: этим ключом можно только синхронизировать файлы в каталог сайта, оболочки по нему нет.
