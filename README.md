# Живой аквариум

Интерактивный 3D-аквариум на Three.js: маленький подводный мир, который живёт сам по себе.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

Первая загрузка занимает несколько секунд: сцена строится процедурно (карта высот для креветок и улиток, мох, растения).

## Управление

| Действие | Как |
|---|---|
| Вращение / зум | мышь (ЛКМ, колесо), ПКМ — панорама |
| Выбрать рыбку | клик по ней (карточка, слежение камерой, переименование ✎) |
| Постучать по стеклу | клик по стеклу |
| Кормить | кнопка или `F` |
| Наблюдать / Cinematic | кнопки или `O` / `C`, выход — `Esc` |
| Скрыть интерфейс | `H` |

## Структура

```
src/
  main.js              рендерер, свет, ввод, главный цикл
  fx/shaderPatch.js    общие шейдерные доработки: каустики, колыхание растений, работа хвоста
  fx/particles.js      пузырьки (слияние/деление), взвесь, лучи света, корм
  fx/post.js           bloom, depth of field, грейдинг, letterbox
  fx/director.js       камера: пресеты, слежение, cinematic и режим наблюдения
  fx/audio.js          синтезированный звук: вода, фильтр, пузырьки, эмбиент
  world/tank.js        аквариум, стекло, вода, песок, фильтр, LED
  world/decor.js       замок, коряга, корабль, сундук, пещера, руины, водолаз…
  world/plants.js      валлиснерия, эхинодорусы, стебельки, мох, кораллы, актиния
  world/daycycle.js    утро / день / вечер / ночь
  life/species.js      12 видов: форма, окраска, плавники, манера плавания, характер
  life/fishModel.js    процедурная модель рыбы
  life/fish.js         ИИ рыбы: состояния, стаи, территория, игры, память
  life/critters.js     креветки, улитки, крабик
  life/ecosystem.js    мир: истории, случайные и редкие события, кормление, секреты
  ui/ui.js             минимальный интерфейс
```

Имена рыб и найденные секреты сохраняются в `localStorage`, поэтому характер и имя конкретной рыбки сохраняются между запусками.
